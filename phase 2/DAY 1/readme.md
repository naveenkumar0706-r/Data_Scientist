# Insurance Prediction using Logistic Regression

## 📌 Introduction
This project predicts whether a person will buy insurance or not using the **Logistic Regression** Machine Learning algorithm.

The model is trained using a dataset containing the age of people and their insurance purchase status.

---

## 🚀 Features
- Data preprocessing
- Logistic Regression model training
- Model prediction
- Accuracy calculation
- Data visualization using Matplotlib

---

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
