# HR Analytics Project

## 📌 Introduction
The HR Analytics project is used to analyze employee data and predict employee attrition using Machine Learning.  
This helps organizations improve employee retention and make better HR decisions.

---

## 🚀 Features
- Employee data analysis
- Data visualization
- Attrition prediction
- Machine Learning model training
- Model evaluation
- Save trained model using Joblib

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
